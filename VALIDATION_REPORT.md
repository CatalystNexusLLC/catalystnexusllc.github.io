# AURION Beta Portal Validation Report 0.2.1

This report is regenerated by the top-level release build. The source validation gates are:

```text
python -m compileall -q api/app api/tests scripts
node --check site/app.js
python scripts/validate_portal.py
python scripts/check_workflow_pins.py
PYTHONPATH=api python -m unittest discover -s api/tests -v
```

The final report records exact command results, SQL/static consistency checks, terms and catalog hashes, archive and credential scans, and any live acceptance work that remains for PostgreSQL, OAuth, Pages, protected workflows, and representative operating systems.

No remote GitHub or production infrastructure result is claimed by this source report unless evidence from the actual protected environment is attached.
