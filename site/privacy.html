Beta Portal Privacy Notice

Catalyst Nexus LLC operates this portal through Guy Grubbs, owner and authorized representative.

Portal records

The portal stores the immutable GitHub numeric account ID, current username and username history, signer name, registration choices, affirmative consent records, terms and privacy versions, installation and coordination UUIDs, requested branch records, release-catalog metadata, checkout timestamps, exact assets, package timestamps, and cryptographic digests. Consent evidence uses keyed fingerprints for the connecting address and browser identifier rather than retaining the raw values.

Local assistant information

Prompts, transcripts, model output, embeddings, memory, training or adaptation state, local workspaces, ticket source, service databases, credentials, and logs stay in the assistant's local folders unless the user separately enables and configures a network feature. Registration and checkout do not upload those local contents.

Purposes and retention

Records support identity verification, beta administration, participant branch provisioning, direct release delivery, integrity evidence, security review, support, and contractual records. Production operators must publish retention periods and an access, correction, and deletion process. Some records may need to be preserved for security, fraud prevention, contractual evidence, or legal obligations.

Security controls

The API validates a signed OAuth state, stores the numeric GitHub identity separately from the current login, discards the provider access token after validation, uses signed HttpOnly session cookies and CSRF protection, and restricts writes to the configured HTTPS origin. Production deployment also requires secret storage, least-privilege database access, protected GitHub environments, review, monitoring, and backups.

Local deletion

Portal deletion requests do not remove files from a user's computer. Use the launcher backup and removal controls for local data. Full local removal can permanently destroy memory and training state unless a verified backup exists.
